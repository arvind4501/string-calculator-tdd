# Incubyte TDD Assessment

This repository contains the implementation of the String Calculator Kata using Test-Driven Development (TDD) principles.

## Functionality Overview

The String Calculator should:

- Handle empty string input
- Handle any amount of numbers
- Handle new lines between numbers
- Support custom delimiters
- Throw exception for negative numbers
- Ignore numbers > 1000
- Support any length of Delimiters
- Allow multiple delimiters


## Requirements

- Ruby 3.0.0 or higher
- Bundler
- RSpec 3.x


## Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/arvind4501/string-calculator-tdd.git
   cd string-calculator-tdd

2. Bundle dependencies:

    ```bash
    bundle install

3. Run Tests:
    ``` bash
    bundle exec rspec
